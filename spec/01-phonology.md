# 01. Phonology & Orthography

Promta uses a strict **15-letter alphabet** with one-to-one letter-to-sound correspondence. Every letter has a single invariant pronunciation.

## 1. Alphabet (15 Letters)

### Vowels (5)

| Letter | IPA | English Approximation |
| :--- | :--- | :--- |
| **a** | /ɑ/ | f**a**ther |
| **e** | /ɛ/ | b**e**t |
| **i** | /i/ | mach**i**ne |
| **o** | /o/ | **o**r / g**o** |
| **u** | /u/ | r**u**le |

### Consonants (10)

| Letter | IPA | English Approximation |
| :--- | :--- | :--- |
| **p** | /p/ | **p**in |
| **d** | /d/ | **d**og |
| **t** | /t/ | **t**op |
| **g** | /ɡ/ | **g**o (always hard) |
| **k** | /k/ | **k**ey (replaces hard *c* and *q*) |
| **s** | /s/ | **s**un |
| **m** | /m/ | **m**ap |
| **n** | /n/ | **n**et |
| **l** | /l/ | **l**og |
| **r** | /r/ | **r**un |

### Forbidden Letters

The remaining 11 letters of the ISO basic Latin alphabet never appear in native Promta words:
`b, c, f, h, j, q, v, w, x, y, z`

*(Proper nouns and acronyms from external languages, such as `AI` or `Promta` when capitalized, may be preserved in running text or adapted phonetically—for example, `Gugel` for Google, `Kitapu` for GitHub.)*

## 2. Syllable Structure: `(C)V(N)`

Every syllable in Promta strictly follows the template **`(C)V(N)`**:

- **`C` (Optional Onset):** At most **one** consonant from `{p, d, t, g, k, s, m, n, l, r}`.
- **`V` (Mandatory Nucleus):** Exactly **one** vowel from `{a, e, i, o, u}`. Adjacent vowels form separate syllables (hiatus, e.g., `mi-a`, `ku-a`).
- **`N` (Optional Coda):** At most **one** nasal consonant from `{m, n}`.

### No Consonant Clusters

Consonant clusters are prohibited within a syllable. Onset clusters in English loan roots are simplified or split by epenthesis:

- *translate* -> **tansa** (`tan-sa`, dropping `r`)
- *prime* -> **pime** (`pi-me`, dropping `r`)
- *protocol* -> **potokola** (`po-to-ko-la`, dropping `r`)
- *project* -> **poreka** (`po-re-ka`, dropping `j` and `ct`)
